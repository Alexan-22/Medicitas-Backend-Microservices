\# MediCitas Backend



Sistema de Gestión de Citas Médicas basado en Microservicios.



\## Tecnologías



\- Java 17

\- Spring Boot

\- Spring Cloud

\- Eureka Server

\- API Gateway

\- OpenFeign

\- PostgreSQL

\- JUnit 5



\## Microservicios



\- Auth Service

\- Patient Service

\- Doctor Service

\- Appointment Service

\- Notification Service

\- Report Service



\## Ejecución



1\. Ejecutar Eureka Server.

2\. Ejecutar Auth Service.

3\. Ejecutar Patient Service.

4\. Ejecutar Doctor Service.

5\. Ejecutar Appointment Service.

6\. Ejecutar Notification Service.

7\. Ejecutar Report Service.

8\. Ejecutar API Gateway.
